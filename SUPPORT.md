# Support

- **Questions and usage help:** open a GitHub Discussion, or an issue if Discussions are not enabled.
- **Bugs and feature requests:** open an issue using the templates.
- **Security vulnerabilities:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Documentation:** start with [docs/GETTING-STARTED.md](docs/GETTING-STARTED.md) and the [wiki](docs/wiki/index.md).
